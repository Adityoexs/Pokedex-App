# Pokedex App

A React + TypeScript Pokemon browsing app built with Vite, TanStack Query, and Tailwind CSS.

## Local Setup

```bash
# 1. Clone the repository
git clone https://github.com/Adityoexs/Pokedex-App.git
cd Pokedex-App

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Open **http://localhost:5173** in your browser.
