# Pokédex App

A web-based Pokédex application to browse Pokémon, view Pokémon details, and filter Pokémon by type.

## Features

- Browse a list of Pokémon
- View detailed information for each Pokémon
- Filter Pokémon by type
- Loading and error states
- Unit and integration tests

## Tech Stack

- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Tailwind CSS
- Jest
- Testing Library
- MSW

## Getting Started

1. Clone the repository

   ```bash
   git clone https://github.com/Adityoexs/Pokedex-App.git
   cd Pokedex-App
   ```


2. Install dependencies

   ```bash
   npm install
   ```

3. Run the development server

   ```bash
   npm run dev
   ```

4. Run tests

   ```bash
   npx jest --config .\jest.config.cjs or
   npm run test:coverage
   ```

5. Build for production

   ```bash
   npm run build
   ```

## Type Filter Notes

The type filter displays Pokémon based on the selected type.  
Use the **Clear** button to return to the full unfiltered list.
